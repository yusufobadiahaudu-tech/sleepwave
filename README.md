# SleepWave

SleepWave is a calming sleep-sounds mixer for iOS and Android, built with Expo and React Native.

## Included

- Layer multiple sleep sounds at once
- Individual volume controls
- Sleep timers
- Saved mixes with local persistence
- Background audio configuration
- RevenueCat-ready premium entitlements
- A locally bundled looping fan sound with a steady low motor hum and airflow texture

## Run locally

Install pnpm, then run:

    pnpm install
    pnpm --filter @workspace/sleepwave run dev

Typecheck with:

    pnpm --filter @workspace/sleepwave run typecheck

RevenueCat public SDK keys and store products still need to be configured for production purchases.
